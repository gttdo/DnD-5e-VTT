# Board-taxonomy icons — credits

**Token kinds** (`tkind_*`) and **creature types** (`ctype_*`) derive from
**game-icons.net** (**CC BY 3.0**), normalized for this project: background removed,
`fill="currentColor"`, 24×24 (viewBox 0 0 512 512).

**Spell-area shapes** (`area_*`) and **creature sizes** (`size_*`) are project-original
geometric icons (filled-outline, hand-authored).
